# Iwara Plus

[English](README.md) · 简体中文

[Sleazy Fork 安装页](https://sleazyfork.org/en/scripts/605034)

[安装脚本](https://raw.githubusercontent.com/lhYanghc/iwara-plus/main/iwara-plus.user.js) · [版本发布](https://github.com/lhYanghc/iwara-plus/releases) · [报告问题](https://github.com/lhYanghc/iwara-plus/issues)

将 [Neko0 Iwara 增强](https://github.com/nekozero/neko0-web-tools/blob/master/automation/iwara.js) 和 [Theatre for iwara](https://sleazyfork.org/zh-CN/scripts/543437-theatre-for-iwara) 的主要功能整合为一个油猴脚本。独立实现统一的工具栏、播放器布局和 SPA 生命周期，无 jQuery、Webpack Hacks 或远程运行时依赖。

## 安装

1. 打开 Chrome 中现有的 Tampermonkey 管理面板，先禁用 `[Neko0] Iwara 增强` 和 `Theatre for iwara`，保留它们以便回退。
2. 点击上方「安装脚本」，在脚本管理器中确认安装。也可以新建脚本，粘贴 `iwara-plus.user.js` 的全部内容并按 Ctrl+S 保存，或通过 Tampermonkey「实用工具 → 从文件导入」导入。
3. 刷新 Iwara 视频页。作品详情上方应出现 Iwara Plus 工具栏，播放器控制栏也会出现影院按钮。

融合以公开源码 Neko0 1.3.0 / Theatre 1.1 为功能参考。此项目不是原作者或 Iwara 官方发布的合并版本。自动测试不代表对真实网站所有版本、账户和播放场景的兼容保证。

## 功能

- 五种文件名格式，候选下拉框显示当前作品最终会复制的完整名称（已清理 Windows 非法字符），并随标题、作者和日期加载自动更新；框外不重复展示名称。
- 独立复制、Source 下载、打开封面，以及明确点击后执行的复制＋喜欢＋关注＋下载。
- 可记忆影院模式，切换按钮位于设置与全屏键之间；退出时恢复播放器原位置，底部不另设影院按钮。
- 扩展操作按钮复用网站原生 button/text 样式，播放器按钮复用 Video.js 原生图标，功能栏不添加独立背景配色。
- 原始喜欢数与观看数保留在「赞、添加到、下载、分享」操作行最右端，使用原节点以保留网站实时更新。下方为两段横线与居中的镂空 V 形箭头，继承网站文字配色；复制名称、下载等增强功能默认折起，点击箭头展开或收起（展开时箭头朝上）；进入另一作品时重新折起。
- 横线与箭头始终位于增强功能下缘：展开时随内容向下移动，收起时随内容向上卷回。使用自适应高度的卷轴揭示动画，可在动画中反向切换；系统设置减少动态效果时立即切换。收起区域不参与键盘导航。增强区域透明，命名选择框复用网站 inputField 主题样式，随网页明暗主题更新。
- 箭头在功能区动画基本结束后再翻转：延迟 300 毫秒开始，翻转持续 280 毫秒，展开与收起对称。
- 影院播放器位于视频内容容器内部的独立区域，不修改网站 `.content` 的布局方向。高度按实际可用容器宽度计算，左侧菜单展开、窗口变窄时同步缩放；下方详情与原始右侧栏保留原网格。
- 默认开启影院布局：上方通栏视频，下方左侧功能栏（含网站原有视频操作按钮）与标题作者详情，右侧保留原始点赞用户等侧栏。功能栏随页面滚动，位于详情顶部。
- 默认打开视频时保持暂停。时长右侧、小窗按钮左侧的「自动播放」开关会记住下次打开视频时是否允许网站自动起播。单击画面或加载圆圈可以播放或暂停，双击画面可以进入或退出全屏。
- 点击画面或加载圆圈后，焦点会交给播放器。此时单按 **I** 切换浏览器画中画，单按 **T** 切换剧场模式。
- 自动选择 Source，可关闭；只在发现新的 Source 菜单项时选择，避免持续覆盖手动操作。
- 分辨率与播放帧率估算，横竖屏均适用；低于 1080p 或约 60 fps 时标色。
- 分辨率与播放帧率估算直接显示在原始操作行右侧的视频数据区，增强功能收起时仍可见，保留低画质颜色提醒。展开箭头通过上下镜像翻转改变方向。
- 播放估算复用原始统计数字的字体、尺寸与粗细，与喜欢数、观看数组成同一组；窄屏时整组移到下一行，极窄时组内继续折行以避免溢出。
- 点赞成功后，原始点赞按钮整体变红，文字和图标保持清晰；取消点赞后恢复网站原有样式。油猴脚本列表使用 Iwara 官方 logo 图标。
- 异步页面切换时回收旧按钮、请求、播放器事件和帧回调。日期接口失败不阻塞其他功能。

## 使用说明与限制

- 一键操作会向网站发出喜欢、关注和下载操作；已经识别为喜欢/关注的按钮不会再次点击。网站响应是否成功需以页面结果为准；未知状态不会猜测点击。
- 下载使用网站提供的 Source 链接，文件保存由浏览器处理。若链接未加载，先展开网站下载菜单。复制的命名不会强制应用到下载文件名。
- 封面按钮打开原图，可在新页自行保存。
- 帧率是播放时的估算，不是文件编码元数据；暂停、变速、后台或未播放时不提供可靠帧率。需浏览器支持 requestVideoFrameCallback。
- 新脚本无法读取另一个油猴脚本的私有 GM 设置。文件名格式需要重新选择；同域的 Theatre `player-theatre` 偏好会在首次运行时读取。
- 保留网站年龄提示，由用户自行处理。
- 网站 DOM、图标或下载菜单结构变化可能需要更新选择器。请不要同时运行原来的两个脚本。

## 开发验证

Node.js 20.19+（建议 22/24）与本地 Chrome，运行 `pnpm install --ignore-scripts`、`pnpm check`、`pnpm test`。浏览器测试以无头 Chrome 的临时会话运行，本地拦截全部请求，不使用个人 Chrome 配置。

自动测试覆盖影院恢复、SPA 切换、重复注入、下载缺失保护、已喜欢状态、元数据失败、竖屏画质与播放器替换。另以模拟网站结构的本地浏览器页面验证 390/600/1000/1440 像素宽度下侧栏开合、卷轴动画、动画中反向切换、明暗主题和减少动态效果。测试不能替代网站实测和视频播放验证。
